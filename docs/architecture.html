三条核心设计主线 Three Design Pillars
PILLAR 01

空间计算下推

空间 / 标量 / 全文 / 向量 / JSON 五模一条 SQL 进 SeekDB；距离、包含、连接、聚合、缓冲区全部由数据库内核完成。

铁律：LLM 不算几何——不写坐标、不猜距离、不凭文字判断顺路。

WHERE cat=:cat AND status=1 AND rating>=4.0 AND _ST_Dwithin(loc, ST_GeomFromText('POINT(...)'), 0.02) AND MATCH(name) AGAINST(:kw IN BOOLEAN MODE) ORDER BY cosine_distance(emb,:qvec) APPROXIMATE LIMIT 60;
PILLAR 02

结构化空间状态

Spatial State 是 JSON 一等公民：session_id / scene / version / constraints / plan / candidates / layers / decision。

每个 steps[i] / layers[j] 带 derived_from 依赖图；用户改约束 → 反向标记 stale → 仅重算受影响节点，未变节点复用缓存。

PILLAR 03

Skill 插件化

SpatialSkill（ABC + Pydantic v2）统一基类；@register_skill 装饰器 + discover() 包扫描；Pydantic schema 自动导出 MCP tools/list。

新增场景核心零改动：只加一个 Skill 包 + 增量 migration + 图层 JSON，不动 L2 状态图骨架与 Query Builder。

空间列 · 标准几何类型
POINT / LINESTRING / POLYGON / MULTI…，建列 NOT NULL（SRID 0，坐标按 WGS84 经纬度存值）。
本机 SRS 表仅 SRID 0；声明 SRID 4326 仍报 ERROR 3548，注册方式待实测。
SPATIAL KEY（MBR）
SPATIAL KEY idx (col)；关系谓词 ST_Intersects / ST_Contains / ST_Within / ST_Buffer。
距离圈选（已实测）
OB 私有 _ST_Dwithin(g1,g2,d)（d 单位是度）；ST_Distance_Sphere 返回米（SRID 0 下 A=0 / B=1478.8m 实测正确）。
VECTOR KEY + HNSW（cosine，已实测）
VECTOR(1024) BGE-m3 直用；ANN 写法 ORDER BY cosine_distance(emb,:q) APPROXIMATE LIMIT k；EXPLAIN 命中 VECTOR INDEX SCAN。
混合查询 · ADAPTIVE 预过滤（V1.4 复验通过）
执行计划 SUBPLAN FILTER → VECTOR INDEX ADAPTIVE SCAN (PRE-FILTER) → TABLE GET 回表，向量扫描同步做空间/标量/全文预过滤。
两阶段写法（圈选极小场景显式先物化候选）保留为兜底。
第五模 · 全文检索（ngram，已实测）
FULLTEXT KEY ... WITH PARSER ngram PARSER_PROPERTIES=(ngram_token_size=2) + MATCH ... AGAINST，中文「咖啡」score 0.240 命中。
🚫 函数边界：交集 / 合并多边形不可下推
V1.4 确认不存在：ST_Intersection / ST_Union_Agg（ERROR 1305）——交并类多边形运算走应用层 Shapely 或高德侧。
可下推：ST_Distance_Sphere / ST_Distance / _ST_Dwithin / ST_Intersects / ST_Contains / ST_Within / ST_Buffer / ST_Centroid / ST_Area。
🚫 DDL 禁项（单机版 V1.4）
禁写：REPLICA_NUM（库/表均 ERROR 1064）、ORGANIZATION INDEX / TABLET_SIZE / USE_BLOOM_FILTER / BLOCK_SIZE 等分布式选项；向量索引 LIB=VSAG 可省。
干净模板以架构文档 §6.3 正式 DDL 为准（原 backup/v140_schema.sql 已清理）。
空间连接与聚合
… JOIN grid ON ST_Contains(g.poly, s.loc) GROUP BY grid_id；等时圈多边形回传批量筛选。
实测（5 行样本）：聚合结果正确，但 EXPLAIN = NESTED-LOOP JOIN + 双侧全扫，未走空间索引；10 万级索引加速待复验。
JSON 列
JSON 类型 + JSON_EXTRACT / -> 操作符；attrs 灵活属性直接入库。
同库五模一体行
一行 dim_poi 同时承载标量 attrs + POINT + VECTOR(1024) + FULLTEXT + JSON，不引第二套向量库。
部署形态（Docker）
镜像 quay.io/oceanbase/seekdb:latest · 容器 seekdb · volume seekdb_data:/var/lib/seekdb · -e MEMORY_LIMIT=2G · --restart unless-stopped。
V1.3 Windows 原生（D:\seekdb）已停止、改手动、可回滚；两实例共用 2881，同一时刻只能起一个。
🐳 Docker 运维：docker start/stop/restart seekdb · docker logs -f seekdb（等 "Seekdb started"）· docker exec -it seekdb sh · 备份 mysqldump -h 127.0.0.1 -P 2881 -uroot --ssl-mode=DISABLED --databases geomind。 自启前提：Docker Desktop 配置为开机自启（--restart unless-stopped 仅在 Docker Desktop 运行时生效）。 回滚：docker stop seekdb → Start-Service seekdb 即恢复 V1.3 原生。
