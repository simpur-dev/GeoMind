### 5. 本轮踩坑（7 个，都已定位根因并修）
1. **`discover()` 受 import 缓存影响**：第二次 discover 时模块已在 `sys.modules`，装饰器不再执行 → 注册表空。修：discover 幂等（已缓存跳过），测试隔离改用快照恢复。
2. **reload 会重定义 SkillRegistry 类**：reload `backend.skills.registry` 后，新注册的 Skill 进新类单例，旧代码持有旧实例 → "注册了却查不到"。修：discover 绝不 reload。
3. **`walk_packages` 只扫一层不够**：原子/场景 Skill 在子包，一层 `iter_modules` 只能发现 2 个。修：递归 `walk_packages`。
4. **`_extract_columns` 按单表校验**：JOIN 查询里另一张表的列被误判。修：传表名元组，按并集校验。
5. **`validate()` 不重新提取列**：篡改 SQL 后 `cq.columns` 还是旧值。修：validate 从 SQL 重新提取并比对。
6. **两个 version 源不一致**：JSON 内的 version 与表的 version 列各玩各的，save 后 load 版本号不涨。修：表的 version 列为权威，load 时同步。
7. **FastMCP 不接受 `**kwargs` handler**（当成必填字段）；且 `f.default!r` 对 default_factory 字段生成 `PydanticUndefined` 字面量。修：exec 生成显式签名函数，参数统一 `=None`，函数体过滤 None 后交 Pydantic。
8. **checkpointer 每次新建**：`Command(resume=...)` 报 "Cannot use Command without checkpointer" / KeyError 'query'。修：进程内共享 `MemorySaver` 单例。
9. **意图器把"安静"当全文关键词**：`'+安静 +自习'` AND 语义命中 0 行（"安静"是 attrs 标签不在名称里）。修：全文关键词只放类目词，属性词走语义向量。
